Unicode Character Inspector

See what your text is really made of

Paste or type text to get a per-character breakdown: the glyph, its Unicode code point, general category, UTF-8 byte sequence, UTF-16 code units, and the JS, HTML, and CSS escape forms. Invisible characters and likely confusables are flagged. Nothing leaves this page.

A complete offline names database for every Unicode code point is not practical to ship in a single file, so this tool derives official names for ASCII and Latin-1 control and printable characters and labels everything else by its general category and block. Treat non-Latin names as approximate.
